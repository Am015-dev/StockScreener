A distance, not a probability — why no percentage is shown

Converting this distance into an actual default probability needs a calibration table built from real historical defaults, which the free data source behind this project does not provide. Without that table, the raw formula for it returns 0.000000% even for companies that do go on to default — accurate to the arithmetic and wrong about the world. So no percentage is quoted here; the distance itself is shown instead of a fabricated one.
